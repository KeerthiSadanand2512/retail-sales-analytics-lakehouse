# Source data

Download [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail), attributed to Daqing Chen (2015), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Store the workbook and converted CSV outside Git. Use `../scripts/prepare_data.py` and follow `../docs/setup.md`. The converter preserves rows and emits ISO timestamp strings. A first-10,000-row sample is for learning only.
